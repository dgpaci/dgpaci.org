> The difference between a piece of code on GitHub and an open-source project is that an
> open-source project solves problems and use cases for its users, not just the author’s one-off
> need.
>
> — [How AI is changing open source](https://enblog.eischmann.cz/2026/07/23/how-ai-is-changing-open-source/)

Tanto codice ma inutilizzato, senza alcun grado di affidabilità, anche questo è l’apporto dell’IA
all’open source che a questo punto potrebbe davvero essere finito…
